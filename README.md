Task 1 (Easy) – Password Generator
Description

Develop a Python application that generates secure and customizable passwords using letters, numbers, and symbols.

Features
Random Password Generation
Custom Password Length (3–128)
Includes Letters, Numbers, and Symbols
Secure Random Password Generation
Generate Multiple Passwords
Input Validation


Technologies Used

Python
Random Module (secrets)
String Module
Task Workflow
Take password length as input.
Include letters, numbers, and symbols.
Generate a random password.
Display the generated password.
Allow users to generate multiple passwords.


How to Run

Open the project folder.

python password_generator.py
